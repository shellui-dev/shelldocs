# ShellDocs.Templates

The templates `shelldocs init` and `shelldocs add` use to scaffold [ShellDocs](https://shelldocs.shellui.dev) sites and pages. It isn't meant to be referenced directly; install the CLI instead:

```bash
dotnet tool install --global ShellDocs.CLI --prerelease
shelldocs init
```
